# Análisis de Clientes Bancarios - Proyecto de Portafolio

## 🎯 Objetivo
Simular el trabajo de un analista de base de datos en el sector bancario:
diseñar una base de datos relacional, limpiar y transformar datos con SQL,
y visualizar los resultados en un dashboard interactivo en Power BI.

## 🛠️ Herramientas
- **MySQL Workbench:** Creación de la base de datos y consultas SQL.
- **SQL (MySQL):** CREATE, INSERT, JOIN de 3 tablas, CASE, COALESCE, GROUP BY.
- **Power BI Desktop:** Dashboard interactivo con 5 visuales.
- **CSV:** Exportación de resultados para el dashboard.

## 🔍 Consulta SQL clave

Une 3 tablas y calcula el saldo actual con CASE y COALESCE.

## 📊 Dashboard en Power BI

![Dashboard de Clientes Bancarios](Dashboard_Banca.png)

### Visuales incluidos:
1. Tarjeta KPI: Saldo total del banco (S/ 14,201.50).
2. Gráfico de barras: Saldo por ciudad.
3. Gráfico circular: Distribución por tipo de cuenta.
4. Tabla de detalle: Clientes con su saldo actual.
5. Segmentación: Filtro interactivo por ciudad.

## 💡 Hallazgos Clave
- El saldo total del banco es de S/ 14,201.50.
- Trujillo concentra el mayor saldo individual (Jose Flores, S/ 5,900.75).
- La cuenta de Ahorros representa el 69.36% del saldo total.

## 🎓 Habilidades Demostradas
- Diseño de base de datos relacional (3 tablas con FK).
- Consultas SQL avanzadas: JOIN múltiple, CASE, COALESCE, GROUP BY.
- Limpieza y transformación de datos.
- Visualización de datos en Power BI.
